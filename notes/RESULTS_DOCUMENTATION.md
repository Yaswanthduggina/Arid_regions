### 1. ML Input Files (`ml_input/`)

#### `barmer_ml_ready.csv`, `bikaner_ml_ready.csv`, `jaisalmer_ml_ready.csv`, `jodhpur_ml_ready.csv`

**How Calculated:**
- Generated by `scripts/ml_shap/01_prepare_dataset.py`
- Loads hourly ETo data from `ET0_new/{city}_hourly_ETo.csv`
- Filters to daytime hours only (ETo > 0) to focus on active evaporation
- Adds temporal features: month, hour, season, year
- Season assignment: Summer (Apr-Jun), Monsoon (Jul-Sep), Post-Monsoon (Oct-Nov), Winter (Dec-Mar)

**File Structure:**
```csv
datetime,T,RH,WS,Rs,P,ETo_mm_hr,month,hour,season,year
2001-01-01 01:00,15.2,65.0,2.1,0.00,101.3,0.045,1,1,Winter,2001
...
```

**What It Represents:**
- Machine learning-ready dataset for each city
- Contains ~215,000 rows per city (daytime hours only from 25 years)
- Input features (T, RH, WS, Rs, P) for XGBoost training
- Target variable (ETo_mm_hr) for supervised learning
- Temporal features for seasonal analysis

**Key Statistics (from dataset_summary.csv):**
- Barmer: 215,588 rows, ETo mean = 0.2852 mm/hr, max = 1.4228 mm/hr
- Bikaner: 216,063 rows, ETo mean = 0.2783 mm/hr, max = 1.5256 mm/hr
- Jaisalmer: 215,894 rows, ETo mean = 0.2914 mm/hr, max = 1.4674 mm/hr
- Jodhpur: 215,794 rows, ETo mean = 0.2689 mm/hr, max = 1.4103 mm/hr

### 3. Metrics Files

#### `metrics_all_cities.csv`

**How Calculated:**
- Generated by `scripts/ml_shap/02_train_xgboost.py`
- Uses 5-fold TimeSeriesSplit cross-validation
- Calculates metrics for each fold, then averages across folds
- Metrics calculated:
  - **R²**: Coefficient of determination (fit quality)
  - **RMSE**: Root Mean Square Error (absolute error in mm/hr)
  - **MAE**: Mean Absolute Error (average deviation in mm/hr)
  - **NSE**: Nash-Sutcliffe Efficiency (hydrological model accuracy, >0.9 is excellent)
  - **Bias**: Mean prediction error (positive = overestimation)

**File Structure:**
```csv
city,R2,RMSE,MAE,NSE,Bias
barmer,0.9987,0.0099,0.006,0.9987,0.0002
bikaner,0.9986,0.0103,0.0063,0.9986,0.0002
jaisalmer,0.9986,0.0104,0.0064,0.9986,0.0003
jodhpur,0.9988,0.0096,0.0057,0.9988,-0.0002
```

**What It Represents:**
- Validation that XGBoost models perfectly learned FAO-56 physics
- R² > 0.998 and NSE > 0.998 indicate near-perfect fit
- Bias ≈ 0 indicates no systematic over/under-estimation
- Used in Table 1 of paper tables

### 4. SHAP Analysis Files (`shap/`)

#### `barmer_shap_values.csv`, `bikaner_shap_values.csv`, `jaisalmer_shap_values.csv`, `jodhpur_shap_values.csv`

**How Calculated:**
- Generated by `scripts/ml_shap/03_shap_analysis.py`
- Uses stratified random sample of 20,000 rows per city (proportional to months)
- Calculates TreeSHAP values using `shap.TreeExplainer`
- SHAP values represent contribution of each feature to each prediction in mm/hr

**File Structure:**
```csv
datetime,T,RH,WS,Rs,P,month,season
2001-04-15 13:00,0.045,-0.012,0.023,0.156,0.002,4,Summer
...
```

**What It Represents:**
- SHAP values for each feature (T, RH, WS, Rs, P) for each sampled hour
- Positive SHAP = feature increases ETo
- Negative SHAP = feature decreases ETo
- Magnitude = importance of feature for that prediction
- Used for all SHAP plots and analyses

**Sample Size:** 20,000 rows per city (stratified by month for representativeness)

---

#### `cross_city_mean_shap.csv`

**How Calculated:**
- Generated by `scripts/ml_shap/03_shap_analysis.py`
- Calculates mean absolute SHAP value for each feature across all samples
- Formula: `mean(|SHAP|)` for each feature

**File Structure:**
```csv
city,T,RH,WS,Rs,P
barmer,0.0423,0.0252,0.0419,0.1874,0.0040
bikaner,0.0422,0.0215,0.0443,0.1810,0.0031
jaisalmer,0.0419,0.0246,0.0466,0.1891,0.0044
jodhpur,0.0412,0.0260,0.0363,0.1821,0.0027
```

**What It Represents:**
- Global feature importance for each city
- Higher value = feature has larger impact on ETo predictions
- Solar Radiation (Rs) is consistently highest (~0.18-0.19 mm/hr)
- Used in Table 2 of paper tables
- Used for cross-city SHAP importance bar chart

**Key Findings:**
- Radiation (Rs) is universally dominant across all cities
- Wind Speed (WS) is highest in Jaisalmer (0.0466) - deeper desert
- Wind Speed is lowest in Jodhpur (0.0363) - more vegetated/urban
- Temperature (T) is consistent across cities (~0.042)
- Pressure (P) has minimal impact (~0.003)

#### `additive_equations_report.txt`

**How Calculated:**
- Generated by `scripts/ml_shap/06_shap_equations.py`
- Loads model base value (expected value from TreeExplainer)
- Calculates mean SHAP values per season and per month
- Constructs additive equations: `ETo = Base + SHAP(T) + SHAP(RH) + SHAP(WS) + SHAP(Rs) + SHAP(P)`

**File Structure:**
```
XGBoost SHAP Additive Contribution Equations
============================================
Formula: ETo = Base_Value + SHAP(T) + SHAP(RH) + SHAP(WS) + SHAP(Rs) + SHAP(P)

--- City: BARMER ---

[Seasonal Equations]
ETo(Summer      ) =  0.285 (Base)  + 0.035 (T )  + 0.010 (RH)  + 0.024 (WS)  + 0.047 (Rs)  + 0.005 (P )
ETo(Monsoon     ) =  0.285 (Base)  + 0.011 (T )  - 0.027 (RH)  + 0.013 (WS)  + 0.002 (Rs)  + 0.004 (P )
...

[Monthly Equations]
ETo(Jan         ) =  0.285 (Base)  - 0.063 (T )  + 0.012 (RH)  - 0.014 (WS)  - 0.029 (Rs)  - 0.002 (P )
...
```

**What It Represents:**
- Interpretable mathematical equations showing how each feature contributes to ETo
- Base value = average ETo for the city
- SHAP coefficients = average contribution of each feature in mm/hr
- Positive coefficient = feature increases ETo on average
- Negative coefficient = feature decreases ETo on average
- Shows seasonal and monthly shifts in dominant drivers

**Key Insights:**
- Summer: Radiation and Temperature have large positive contributions
- Monsoon: Humidity has negative contribution (high RH suppresses ETo)
- Winter: Temperature has negative contribution (cold reduces ETo)
- Radiation is always positive (always contributes to evaporation)

#### `percentage_contributions_report.txt`

**How Calculated:**
- Generated by `scripts/ml_shap/07_shap_percentages.py`
- Calculates mean absolute SHAP values per season and month
- Converts to percentages: `Percentage(F) = |SHAP(F)| / sum(|SHAP(all)|) * 100`

**File Structure:**
```
XGBoost SHAP Percentage Contributions
=====================================
Formula: Percentage(F) = |SHAP(F)| / sum(|SHAP(all_features)|) * 100

--- City: BARMER ---

[Seasonal % Contribution]
Summer       | T:  13.4%  RH:   7.5%  WS:  15.7%  Rs:  61.8%  P:   1.5%
Monsoon      | T:  10.5%  RH:  11.1%  WS:  13.1%  Rs:  63.9%  P:   1.4%
...

[Monthly % Contribution]
Jan          | T:  23.8%  RH:   7.4%  WS:  10.6%  Rs:  57.0%  P:   1.2%
...
```

**What It Represents:**
- Relative importance of each feature as percentage
- Shows how feature importance shifts seasonally
- Radiation consistently 55-65% (dominant driver)
- Temperature importance increases in winter (20-25%)
- Humidity importance increases in monsoon (10-13%)
- Wind importance varies by city and season

**Key Insights:**
- Radiation is always >55% of total contribution
- Temperature becomes more important in winter (less radiation)
- Humidity becomes more important in monsoon (cloudy, rainy)
- Wind is secondary driver (10-17%)
- Pressure is negligible (<2%)

### 5. SHAP Plot Files (`shap/`)

#### `{city}_shap_summary.png` (e.g., `barmer_shap_summary.png`)

**How Calculated:**
- Generated by `scripts/ml_shap/03_shap_analysis.py`
- Uses `shap.summary_plot()` with beeswarm visualization
- Plots SHAP values for all 20,000 samples

**What It Represents:**
- Global SHAP summary plot (beeswarm)
- Y-axis: Features ordered by importance (top = most important)
- X-axis: SHAP value (mm/hr) - how much feature changes ETo
- Color: Feature value (red = high, blue = low)
- Each dot = one hourly prediction

**Interpretation:**
- Features at top have larger SHAP values (more important)
- Red dots on right = high feature value increases ETo
- Blue dots on right = low feature value increases ETo
- Radiation (Rs) is always at top (most important)
- Humidity (RH): Blue on right = low humidity increases ETo (dry air evaporates faster)
- Temperature (T): Red on right = high temperature increases ETo

---

#### `{city}_shap_dependence.png` (e.g., `barmer_shap_dependence.png`)

**How Calculated:**
- Generated by `scripts/ml_shap/03_shap_analysis.py`
- Creates 2×3 grid of scatter plots (5 features, one empty)
- X-axis: Feature value
- Y-axis: SHAP value (mm/hr)
- Color: Feature value (plasma colormap)

**What It Represents:**
- SHAP dependence plots showing relationship between feature value and its impact
- Shows non-linear relationships and feature interactions
- Vertical spread at same X value = interaction with other features

**Interpretation:**
- Linear relationship = direct effect
- Curved relationship = non-linear effect
- Vertical fanning = interaction with other features
- Wind Speed (WS) shows fanning = interacts with humidity
- High wind only increases ETo if humidity is low

---

#### `{city}_monthly_shap_heatmap.png` (e.g., `barmer_monthly_shap_heatmap.png`)

**How Calculated:**
- Generated by `scripts/ml_shap/03_shap_analysis.py`
- Groups SHAP values by month
- Calculates mean absolute SHAP per month per feature
- Plots heatmap with annotations

**What It Represents:**
- Monthly variation in feature importance
- Y-axis: Features (T, RH, WS, Rs, P)
- X-axis: Months (Jan-Dec)
- Color: Mean |SHAP| value (darker = more important)
- Numbers: Exact SHAP values in mm/hr

**Interpretation:**
- Radiation (Rs): High in summer (Apr-Jun), low in winter
- Temperature (T): High in summer, moderate in winter
- Humidity (RH): Spikes in monsoon (Jul-Aug)
- Wind (WS): Varies by city, generally higher in summer
- Shows "regime shift" from summer to monsoon

---

#### `{city}_seasonal_shap.png` (e.g., `barmer_seasonal_shap.png`)

**How Calculated:**
- Generated by `scripts/ml_shap/03_shap_analysis.py`
- Groups SHAP values by season
- Creates boxplots for each feature per season
- Color-coded by season (Summer=red, Monsoon=blue, Post-Monsoon=green, Winter=purple)

**What It Represents:**
- Distribution of SHAP values per season
- Shows spread and outliers in feature contributions
- Most "research paper ready" visualization

**Interpretation:**
- Box height = variability of feature impact
- Median line = typical contribution
- Whiskers = range of typical values
- Radiation box shifts down in winter (less impact)
- Humidity box shifts up in monsoon (more impact)
- Temperature box compresses in winter (less variability)

#### `bias_distribution.png`

**How Calculated:**
- Generated by `scripts/ml_shap/04_cross_city_analysis.py`
- Calculates residuals: Predicted - Observed ETo
- Plots KDE (Kernel Density Estimate) for each city

**What It Represents:**
- Distribution of prediction errors (bias)
- Bell curve shape = normal distribution of errors
- Center at 0 = no systematic bias
- Narrow spread = high precision

**Interpretation:**
- All curves centered at 0 = no systematic over/under-prediction
- Narrow curves = low error variance
- Overlapping curves = similar performance across cities
- Confirms models are unbiased and precise

### 8. Sensitivity Analysis Files (`sensitivity/`)

#### `sensitivity_results.csv`

**How Calculated:**
- Generated by `scripts/ml_shap/08_sensitivity_analysis.py`
- For each city and each feature:
  - Perturbs feature by ±20%, ±10%, ±5%, 0%
  - Makes predictions on perturbed data
  - Calculates % change in mean ETo
- Formula: `Change_% = ((New_ETo - Baseline_ETo) / Baseline_ETo) * 100`

**File Structure:**
```csv
City,Feature,Perturbation_%,Baseline_ETo,New_ETo,Change_%
barmer,T,-20.0,0.2852,0.2516,-11.76
barmer,T,-10.0,0.2852,0.2673,-6.26
barmer,T,0.0,0.2852,0.2852,0.0
barmer,T,10.0,0.2852,0.3034,6.39
barmer,T,20.0,0.2852,0.3203,12.32
...
barmer,Rs,-20.0,0.2852,0.2533,-11.16
barmer,Rs,20.0,0.2852,0.3138,10.03
```

**What It Represents:**
- Sensitivity of ETo predictions to each input feature
- Shows how much ETo changes when features change
- Quantifies model robustness and feature importance

**How to Interpret:**
- Temperature: ±20% → ±12% ETo change (high sensitivity)
- Radiation: ±20% → ±11% ETo change (high sensitivity)
- Humidity: ±20% → ±5% ETo change (moderate sensitivity)
- Wind: ±20% → ±6% ETo change (moderate sensitivity)
- Pressure: ±20% → ±2% ETo change (low sensitivity)
- Linear relationship = proportional response

**Key Findings:**
- Temperature and Radiation have highest sensitivity
- Pressure has lowest sensitivity (consistent with SHAP)
- Response is nearly linear (symmetrical for ± perturbations)
- Validates SHAP importance rankings

#### `{city}_sensitivity_curve.png` (e.g., `barmer_sensitivity_curve.png`)

**How Calculated:**
- Generated by `scripts/ml_shap/08_sensitivity_analysis.py`

- Lines pass through origin (0,0) = no perturbation = no change
- Linear slopes = proportional response
- Confirms SHAP importance rankings
